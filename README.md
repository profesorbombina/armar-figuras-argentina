# Armar Figuras Argentina

Juego web responsive para armar figuras arrastrando fichas en una silueta.

## Version

1.0

## Repositorio sugerido

`armar-figuras-argentina`

## Uso

1. Abrir `index.html`.
2. Escribir el nombre del participante.
3. Elegir el tipo de figura: rombo, cuadrado o triangulo.
4. Configurar la cantidad de fichas y el tiempo.
5. Arrastrar las fichas hacia la figura objetivo.
6. Presionar `Revisar figura` todas las veces que sea necesario.

## Niveles

- Facil: de 1 a 4 fichas.
- Intermedio: de 5 a 10 fichas.
- Avanzado: mas de 10 fichas u objetos para armar.

La actividad termina cuando se completa correctamente la figura, cuando se acaba el tiempo o cuando se presiona finalizar. Al finalizar muestra participante, figura, nivel, fichas configuradas, ubicadas, correctas, pendientes, intentos, precision final, tiempo configurado y tiempo usado.
